# 跨期交易：纸面试运行及切换验收

## 当前可执行入口

从仓库根目录运行，输出目录必须不存在。命令不需要 CTP 账号，不使用券商服务器，也不会撮合未被场景明确指定的成交。

```powershell
.\.venv\Scripts\python.exe -B main.py --paper --output bean-paper-001 --fee-table fees/fee_table.json --pace 0.5
# 在另一个终端查看；也可在运行完成后查看最后一代
.\.venv\Scripts\python.exe -B main.py --workbench --follow bean-paper-001
```

默认使用 [豆一纸面场景](../../examples/paper_bean.jsonl) 和仓库配置。纸面策略流水记录市场输入、参数、触发依据、撤单意图和核验进度；独立纸面柜台事实流水保存受理/成交、会话绑定、每次发单前完整查询。工作台明确标记为模拟，不能替代主终端真实持仓。纸面现金是场景输入，不模拟结算、手续费扣款、交易所排队或真实网络延迟。

工作台只跟随同一代已关闭的副本；超过 15 秒未发布显示过期，结束后标记历史。这个示例若显式加载仓库费率表，三层各获 2 点 × 10 元，毛收益 60 元，12 条腿成交各计模拟费 2 元，共 24 元，模拟净收益 36 元。不是券商实际净收益，也不修改模拟可用资金输入。未指定费率或无法归属时不伪造净收益。

## 对拍清单

1. 输入只够预热时不报单。出现有效决策后需取得同轮委托、成交、人民币资金与逐腿持仓；等待期间失去新报价、信号/参数失效、柜台活动或证据不足时，不得发送。
2. 开 L1 → 挂 L1 止盈 → L2 实成后撤 L1 止盈 → 挂 L2 止盈 → L3 实成后撤 L2 止盈 → 挂 L3 止盈。平完 L3 后恢复 L2 止盈，再退回 L1。此场景总计 **8 张纸面委托，2 张确认撤单，6 手组合的成交（12 条腿明细），最终无活动委托、无策略层、两腿均空**。
3. GUI 过滤同一账户、同一交易日，检查每张委托的配置版本、条件和层号；已撤旧单不能算作保护；未有费用凭据时勿把毛收益叫净收益。
4. 分别运行 `python -m unittest tests.test_runtime_bridge tests.test_paper_acceptance tests.test_shadow_risk tests.test_recovery` 验证发送窗口、成交竞态、关闭/启用止损及隔夜差异。最后运行完整测试而非只看这些用例。

## 迁移、回退与未放行范围

- 旧系统运行时不要同时启动第二个实盘写入者。先在柜台主终端核对所有活动单、可平量和冻结；暂停策略不会撤单。保全原始配置、账本、成交和日终结算资料，备份后恢复到独立演练目录验证。持仓/活单来源不明不接管。
- 新工作台是离线查看/草案导出入口；不会写回正在运行的配置。换参数从新版本回放开始，不修改历史层成本。跨日基线核对一致仅供审计；缺少前日完整证据不授予新日交易权限。
- 本次仅放行离线回放和无网络纸盘。桥拒绝真实引擎，且生产接口拒绝 shadow_only 意图；旧 CLI 不提供实盘旁路。不要把纸面模拟的显式成交、资金或委托号导入生产事实库。
- 真实柜台的组合标识、回报形态、查询限频、自成交防范、费用和应急撤单，仍需在未来**另行授权**的券商模拟环境验证。未经确认不得启动无人值守实盘，也不能将本说明视为批准。
- 演练失败：保留输出库与日志，不从历史快照盲重发；可换新的纸面输出目录重放同一场景。若已有真实挂单或账户损益争议，回到柜台主终端核实并归档证据，不覆盖或清空本地事实记录。
