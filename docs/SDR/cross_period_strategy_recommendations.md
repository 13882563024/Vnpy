# 跨期均值回归策略推荐文档

更新时间：2026-07-29

本文整理当前本地 tick 数据回测中表现较好的跨期品种及推荐策略。回测结果来自：

- 数据：`data/hf_all_full_dedup`
- 脚本：`hf_cross_period_walkforward.py`
- 最新结果目录：`results/hf_roll_adaptive_minpnl_wf`

注意：当前手续费使用 `fee_table_template.csv` 中的模板手续费，不是官方交易所或真实账户手续费。后续实盘前必须替换为真实费率，并重新回测。

## 一、通用策略逻辑

### 1. 合约选择

每个交易日使用上一交易日成交量选择前两大非当月合约，按合约月份排序为：

```text
near = 近月非当月活跃合约
far  = 远月非当月活跃合约
```

策略不交易当月合约。夜盘数据按照中国期货交易日映射到下一交易日。集合竞价时间不参与交易。

### 2. 价差定义

```text
spread = near_mid - far_mid
mid = (bid_price_1 + ask_price_1) / 2
```

均值与波动率：

```text
mean = 最近 N 分钟 spread 均值
sd   = 最近 M 分钟 spread 标准差
```

当前推荐统一使用：

```text
N = 3 分钟
M = 30 分钟
X = 1 倍标准差
```

### 3. 开仓逻辑

当价差低于均值时，做多价差：

```text
spread < mean - threshold * sd

买 near：用 ask 成交
卖 far：用 bid 成交
```

当价差高于均值时，做空价差：

```text
spread > mean + threshold * sd

卖 near：用 bid 成交
买 far：用 ask 成交
```

### 4. 分层加仓

最多持仓 5 手，同一时间只允许同方向持仓。分层阈值：

```text
第 1 手：X
第 2 手：X + 0.3
第 3 手：X + 0.6
第 4 手：X + 0.9
第 5 手：X + 1.2
```

即：

```text
max_positions = 5
layer_step = 0.3
```

### 5. 过滤器逻辑

当前策略里使用和测试过的过滤器可以分成五类：盘口可成交性过滤、两腿同步过滤、成交量比例过滤、临近到期过滤、动量过滤。

#### 5.1 盘口宽度过滤

参数：

```text
width_ticks = 1
```

逻辑：

```text
near_ask - near_bid <= 1 tick
far_ask  - far_bid  <= 1 tick
```

作用：只在两腿盘口都足够紧的时候交易。跨期策略的盈利通常来自较小价差回归，如果盘口已经很宽，真实进出场成本会明显变大，回测信号容易被 bid/ask 成本吃掉。

当前推荐：所有品种都保留。

#### 5.2 报价同步过滤

参数：

```text
sync_s = 0.5
```

逻辑：

```text
abs(near_quote_time - far_quote_time) <= 0.5 秒
```

作用：避免用一条腿的新报价和另一条腿的旧报价拼出虚假价差。跨期 tick 数据里，两腿报价不是天然同时更新，如果不同步，价差信号会偏乐观。

当前推荐：所有品种都保留。

#### 5.3 一档深度过滤

参数：

```text
min_depth = 1
```

逻辑：

```text
min(near_bid_volume_1, near_ask_volume_1, far_bid_volume_1, far_ask_volume_1) >= 1
```

作用：过滤一档无量或异常挂量。当前只是最低可成交性要求，还没有完整模拟 5 手同时吃单的盘口深度，所以实盘前还需要做额外深度压力测试。

当前推荐：所有品种都保留。

#### 5.4 成交量比例过滤

参数：

```text
volume_ratio_max = VR
```

逻辑：

```text
max(near_volume, far_volume) / min(near_volume, far_volume) <= VR
```

如果 `VR = 0`，表示不启用这个过滤器。

作用：避免两腿活跃度差异过大。两腿成交量差距太大时，较不活跃的一腿容易滑价、跳价、成交失败，也容易导致价差回归信号失真。

当前结论：

| 品种 | 推荐 |
|---|---|
| J | 不启用，`VR0` |
| OI | 不启用，`VR0` |
| A | 不启用，`VR0` |
| B | 不启用，`VR0` |
| RM | 启用，`VR10` |

RM 必须保留 `VR10`。不加成交量比例过滤时，RM 收益质量明显变弱。J/OI/A/B 不需要该过滤器，启用后通常会减少交易机会，对最终收益帮助不明显。

#### 5.5 临近到期过滤

参数：

```text
roll_entry_cutoff_days = 3
roll_exit_days = 1
```

开仓过滤逻辑：

```text
如果任一腿距离进入当月 <= 3 个交易日：
    不再新开仓
```

强平逻辑：

```text
如果下一交易日任一腿将进入当月：
    强制平仓
```

作用：减少临近换月阶段继续开仓导致的强平亏损。这个过滤器对 A/B/RM 改善尤其明显，对 J/OI 也有正贡献。

当前推荐：所有推荐品种都使用 `REC3 + REX1`。

#### 5.6 动量过滤

参数：

```text
momentum_min = MOM
```

逻辑：

```text
做多价差时，要求最近 MOM 分钟 spread 不再继续下跌
做空价差时，要求最近 MOM 分钟 spread 不再继续上涨
```

更具体地说：

```text
做多 spread：momentum >= 0
做空 spread：momentum <= 0
```

作用：避免在价差单边发散最剧烈的时候直接逆势开仓。

当前结论：这批最终推荐品种里不作为默认过滤器。J/OI/A/B 的最佳组合不需要 MOM；RM 当前主要依赖 `VR10`，不是 MOM。动量过滤可以作为后续降低尾部风险的备选，但本轮 walk-forward 结果不支持把它列为默认条件。

#### 5.7 脏数据过滤

回测还内置了基础数据清洗：

```text
bid <= 0 或 ask <= 0：过滤
ask < bid：过滤
bid/ask 超出涨跌停：过滤
盘口宽度超过 max_clean_width_ticks：过滤
同合约 mid 瞬时跳变超过 max_clean_jump_ticks：过滤
品种前缀不精确匹配：过滤
```

作用：防止明显错误报价制造虚假的均值回归机会。

当前推荐：所有品种都保留。

#### 5.8 各品种过滤器配置

当前推荐品种的过滤器配置如下：

| 品种 | 盘口宽度 | 报价同步 | 一档深度 | 成交量比例 | 临近到期 | 动量过滤 | 脏数据过滤 |
|---|---|---|---|---|---|---|---|
| J 焦炭 | `W1` | `S0.5` | `D1` | 不用，`VR0` | `REC3 + REX1` | 不用，`MOM0` | 使用 |
| OI 菜油 | `W1` | `S0.5` | `D1` | 不用，`VR0` | `REC3 + REX1` | 不用，`MOM0` | 使用 |
| A 豆一 | `W1` | `S0.5` | `D1` | 不用，`VR0` | `REC3 + REX1` | 不用，`MOM0` | 使用 |
| B 豆二 | `W1` | `S0.5` | `D1` | 不用，`VR0` | `REC3 + REX1` | 不用，`MOM0` | 使用 |
| RM 菜粕 | `W1` | `S0.5` | `D1` | 使用，`VR10` | `REC3 + REX1` | 不用，`MOM0` | 使用 |

简化成策略配置：

```text
J/OI/A/B:
    W1 + S0.5 + D1 + VR0 + REC3 + REX1 + MOM0 + 脏数据过滤

RM:
    W1 + S0.5 + D1 + VR10 + REC3 + REX1 + MOM0 + 脏数据过滤
```

过滤器重要性排序：

| 过滤器 | 使用建议 | 原因 |
|---|---|---|
| `REC3` | 所有推荐品种使用 | 减少临近当月继续开仓带来的强平亏损 |
| `W1/S0.5/D1` | 所有推荐品种使用 | 基础成交可行性过滤，避免宽盘口、旧报价和无量盘口 |
| `VR10` | 仅 RM 使用 | RM 两腿活跃度差异对结果影响较大 |
| `MOM` | 当前不默认使用 | 本轮 walk-forward 不支持作为 J/OI/A/B/RM 的默认过滤器 |

### 6. 临近到期规则

新增推荐规则：

```text
roll_entry_cutoff_days = 3
```

含义：如果任一腿距离进入当月合约小于等于 3 个交易日，不再新开仓。

已有仓位仍按原规则管理；当下一交易日即将进入当月时，强制平仓。

### 7. 回归平仓

旧逻辑使用硬编码：

```text
pnl >= 20
```

新版改为自适应：

```text
min_exit_pnl = max(4 × 单腿单边手续费, 1 × tick_size × 合约乘数)
```

本次推荐品种对应阈值：

| 品种 | 自适应回归平仓阈值 |
|---|---:|
| J | 50 |
| OI | 10 |
| A | 10 |
| B | 10 |
| RM | 10 |

### 8. 止损与强平

平仓优先级：

```text
1. 下一交易日进入当月：强平
2. 单笔亏损达到 stop_loss：止损
3. 持仓超过 max_hold_days：时间止损
4. 回到入场均值且 pnl >= 自适应阈值：回归平仓
```

当前推荐：

```text
max_hold_days = 10
stop_spread_ticks = 0
order_type = market
```

## 五、当前仍需注意的问题

### 1. 手续费仍需替换

当前手续费是模板值，不是官方或账户真实值。实盘前必须替换为真实手续费后重跑。

### 2. 成交深度仍偏乐观

回测使用一档 bid/ask 成交，没有模拟多档吃单、排队、撤单失败和两腿成交延迟。最大 5 手时，这一点尤其重要。

### 3. 两腿成交风险仍未完全反映

当前要求两腿报价同步小于等于 0.5 秒，但真实交易仍可能出现一腿成交、一腿未成交或第二腿滑价。

### 4. RM 仍然偏弱

RM 虽然改善明显，但年化仅 2.60%，对手续费、滑点、成交失败更敏感。

### 5. 后续建议

后续建议优先做：

```text
1. 替换真实手续费重跑
2. 加入一档挂量是否足够 5 手的成交压力测试
3. 测试额外滑点：每腿 +0.5 tick / +1 tick
4. 对 J/OI/A/B 做组合级资金曲线和相关性分析
5. 对 RM 继续扫 VR、H、REC、止损参数
```
